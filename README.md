## About Me

My work brings together AI, automation, and storytelling. I'm interested in how people can use AI more deliberately: give it useful context, define a clear process, and review the result with care.

I turn working methods into reusable skills and workflows, with an emphasis on clarity, consistency, and practical use.

Currently at **Hoang Hoa JSC**. This profile is where I share my personal projects, experiments, and lessons from building with AI.
